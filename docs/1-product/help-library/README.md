# Biblioteca del bot de ayuda Pixy

- `drafts/`: revisión editorial y contraste de fuentes de Gemini. No se carga en runtime.
- `reviews/`: snapshots aceptados, incidencias y mediciones de integración.
- `src/modules/features/caa/library/published.json`: corpus compilado, actualizado por el pipeline y servido tras un nuevo build.
